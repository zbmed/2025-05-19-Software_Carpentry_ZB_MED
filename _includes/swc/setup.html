Miniforge Installation Instructions:

  1. Download and install Miniforge
    Visit the conda-forge download page.
    Download the appropriate Miniforge3 installer:
    • Windows: file with the extension .exe.
    • macOS (Intel): file with MacOSX-x86_64.
    • macOS (Apple Silicon): file with MacOSX-arm64.
    • Linux: File suitable for your architecture (e.g. x86_64, arm64).

    For macOS and Linux, the file is provided as an executable .sh file. Carry out the following steps:

    1. Open a terminal.
    2. Navigate to the directory in which the downloaded .sh file is located. For example:
      cd ~/Downloads
    3. Execute the file with the following command:
      bash Miniforge3-Linux-x86_64.sh (Replace the file name with the corresponding name of the downloaded file.)
    4. Follow the instructions on the screen. Accept the license terms and use the default settings unless otherwise required.
  2. Install Jupyter Notebook, Pandas, Matplotlib and Spyder
    This step is important because we use Jupyter Notebook as a development environment and use additional libraries such as Pandas, Matplotlib, urllib. request and json in the course.
    Open Miniforge Prompt and enter the following commands:
    conda install -c conda-forge notebook pandas matplotlib spyder
    Confirm the Proceed request with "y".
  3. Start Jupyter Notebook
    After installation, you can start Jupyter Notebook with the following command:
    jupyter notebook
